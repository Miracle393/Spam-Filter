# Learning SMS Spam Classification using Logistic Regression

A machine learning project practicing binary text classification using Python and scikit-learn.

## Implemented

- TF-IDF feature extraction for converting SMS text into numerical features
- Logistic Regression classifier
- Training and testing dataset split
- Spam/Ham prediction
- Confusion Matrix for model evaluation
- Binary classification performance metrics practice

## Dataset

UCI SMS Spam Collection Dataset

Classes:
- Ham (Normal messages)
- Spam (Unwanted messages)

## Tools Used

- Python
- Pandas
- NumPy
- scikit-learn
- Jupyter Notebook
- Matplotlib
